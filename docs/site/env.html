متغيرات البيئة وكل ما يُضبط من خارج الكود

الأداة لا تقرأ أي ملف إعدادات خاص بها عدا kirapass_data/settings.json. كل ما عدا ذلك يأتي من سطر الأوامر أو متغيرات البيئة. هذه الصفحة تجمعها كلها في مكان واحد مع القيم الافتراضية وحدودها.

كيف تُقرأ: كل المتغيرات تُقرأ مرة واحدة عند الاستيراد في config.py (وcli.py/server.py للاثنين الخاصين بهما). لذلك تغييرها بعد الإقلاع لا يؤثر — أعد تشغيل الأداة. الاستثناء: connect_timeout وread_timeout يمكن تحديثهما من الواجهة (/api/settings) لأن الكود يعدّل config.CONNECT_TIMEOUT مباشرة.

المتغيرات

المتغيرالافتراضيأين يُقرأالغرض وحدوده
KIRAPASS_HOST127.0.0.1 cli.py (قيمة افتراضية لـ--host) على أي عنوان يُصغي السيرفر. 0.0.0.0 = كل الواجهات (يتطلب رمزاً، ويطبع تحذيراً)
KIRAPASS_PORT8770 cli.py (قيمة افتراضية لـ--port) منفذ الواجهة. int() — قيمة غير رقمية تُسقط البرنامج عند الإقلاع
KIRAPASS_NO_BROWSER(فارغ) cli.py أي قيمة غير فارغة ⇒ لا يُفتح المتصفح تلقائياً (مثل --no-browser)
KIRAPASS_DEBUG(فارغ) server.py · Handler.log_message أي قيمة ⇒ يُطبع كل طلب HTTP في الطرفية (وإلا الطرفية نظيفة)
KIRAPASS_CONNECT_TIMEOUT4.0 config._env_float مهلة فتح المقبس بالثواني. تُقصّ إلى 0.5–120؛ قيمة غير رقمية ⇒ الافتراضي
KIRAPASS_READ_TIMEOUT8.0 config._env_float مهلة انتظار الرد (فحص/معايرة). نفس الحدود
KIRAPASS_ATTACK_READ_TIMEOUT5.0 config._env_float مهلة القراءة أثناء التشغيل الفعلي (new_session(for_attack=True)). أقصر عمداً حتى لا تعلّق الخيوط
KIRAPASS_INTERNET_CHECKS ثلاثة مواقع معروفة config._parse_internet_checks تجاوز مواقع فحص الإنترنت. الصيغة: url|status|text,… (النص اختياري، الحالة افتراضياً 204). إن تُرك فارغاً تُستخدم قائمة google204 / msft / apple
KIRAPASS_AUTO_PACE1 config.AUTO_PACE القيم 0 / no / off ⇒ تعطيل ضبط الوتيرة التلقائي فتبقى الأداة على الرقم الذي كتبه المستخدم بالضبط
KIRAPASS_WARMUP_EVERY25 config.WARMUP_EVERY كل كم محاولة يُطلب صفحة الدخول مرة أخرى لكل خيط (لتجديد الكوكي والحقول المخفية). 0 = مرة واحدة فقط. لا يمكن أن يصبح سالباً (max(0, …))
KIRAPASS_REPORT_RETENTION_DAYS30 config.REPORT_RETENTION_DAYS حذف تلقائي لتقارير runs/ الأقدم من n يوم عند كل حفظ تقرير. 0 ⇒ تعطيل الحذف

أمثلة عملية

# شبكة فحص الإنترنت محجوبة فيها ⇒ استخدم موقعك
KIRAPASS_INTERNET_CHECKS="http://10.0.0.1/generate_204|204" python3 KiraPass.py

# راوتر RADIUS بطيء جداً
KIRAPASS_CONNECT_TIMEOUT=8 KIRAPASS_READ_TIMEOUT=15 python3 KiraPass.py

# وتيرة ثابتة بلا ذكاء (للقياس الدقيق)
KIRAPASS_AUTO_PACE=0 python3 KiraPass.py

# تشغيل بلا متصفح + سجل طلبات كامل للتصحيح
KIRAPASS_NO_BROWSER=1 KIRAPASS_DEBUG=1 python3 KiraPass.py --port 8771

# لا تحذف تقارير قديمة أبداً
KIRAPASS_REPORT_RETENTION_DAYS=0 python3 KiraPass.py
