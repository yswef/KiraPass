نظرة عامة للمطوّر

هذه الصفحة هي الخريطة: ما الملفات الموجودة، ما مسؤولية كل ملف، من يعتمد على من، وما القواعد التي كُتب المشروع عليها. بعدها انتقل إلى المعمارية وتدفق البيانات ثم إلى صفحة الملف الذي ستعدّله.

محتويات الصفحة

المشروع في فقرة واحدة

KiraPass باك-إند بايثون فقط (بلا أي مكتبة خارجية) يشغّل سيرفر HTTP محلياً صغيراً يقدّم صفحة واحدة (ui.html + ui.js + ui.css) وواجهة JSON. الصفحة تجمع من المستخدم: رابط صفحة الدخول، صيغة البطاقة، وقوة التشغيل. السيرفر يقرأ صفحة البوابة ويستنتج شكل الطلب، ثم يتعلّم كيف تبدو صفحة الرفض بإرسال بطاقات تجريبية، ثم يشغّل محركاً متعدد الخيوط يرسل بطاقات ويصنّف كل رد إلى حكم (مقبول/مرفوض/غير واضح/محجوب/…) بسبب مقروء، ويحفظ كل شيء في kirapass_data/.

القاعدةالشرح
config.py لا يستورد من الحزمةلكي يبقى كل رقم في مكان واحد يمكن قراءته وتعديله.
errors.py لا يعرف شيئاً عن المحركيحوّل استثناءً إلى kind فقط.
لا وحدة تستورد engine ما عدا cli/server/selftest/captureيمنع الدوائر ويبقي المحرك قابلاً للاختبار.
الاستيراد داخل الدالة مسموح عند الحاجة فقطمثل from .portals import sanitize_login_url داخل store.migrate لتجنّب دائرة.
لا مكتبات خارجية إطلاقاًقاعدة تصميم صريحة: تعمل على هاتف/جهاز مقفل بدون pip install.

قواعد التصميم السبع (كل واحدة وُلدت من عطل حقيقي)

  1. لا نجاح بلا دليل. Verdict.is_hit صحيح فقط لأكواد ACCEPTED*، وهذه لا تصدر إلا بتحويل خارج البوابة، أو كلمات نجاح متعلَّمة، أو فحص إنترنت حقيقي. fingerprint.py
  2. لا تضيع أي محاولة. مجموع العدّادات = عدد الكروت التي جُرّبت فعلاً؛ المنتج يستخدم put() بحد زمني حتى لا يعلّق الإيقافُ التشغيلَ، وما يُترك يُحسب في dropped. engine.py
  3. خط أساس الرفض متعلَّم لا مفترض. يُبنى من بطاقات تجريبية صحيحة الشكل، ويقارَن بإخفاء القيم المتعلَّمة + الأنماط + تشابه الشكل. بروفايل لا ينتج أي بطاقة يُرفض بسبب واضح بدل المعايرة على أساس فارغ.
  4. التشغيل يُستأنف ولا يُعاد. space_pos + walk_a/walk_b في البروفايل، والصفحة تعيدها مع كل بداية.
  5. عزل لكل خيط. جلسة واحدة تشبه المتصفح لكل عامل: تفتح الصفحة أولاً لتأخذ الكوكي والرمز، وتبتلع النموذج الجديد بعد كل رفض (رموز CSRF تُستخدم مرة).
  6. الأسباب مفاتيح آلية (same_as_rejection_page_exact، net_read_timeout، banned_by_router…) والواجهة تترجمها — فلا شيء مكتوب في مكانين.
  7. كل مجهول يُحفظ ولا يُخمَّن. الردود غير الواضحة تُكتب في kirapass_data/review/ مع كلمات الفرق.
قاعدة صفر (تسبق السبع): لا تُضف أي سلوك «يتجاوز» حجباً أو التواءً أو كابتشا. كل مكان في الكود يتعامل مع الحجب يتوقف ويشرح ويطلب مراجعة مسؤول الشبكة. تعديل هذا السلوك يغيّر طبيعة الأداة القانونية. انظر أماكن الخطر.

من أين أبدأ القراءة؟

  1. cli.py — 189 سطراً، يريك كل مداخل الأداة.
  2. config.py — كل رقم ستحتاج معرفته.
  3. store.py — شكل البروفايل ورياضيات الفضاء (decode_card وcard_at_walk_pos).
  4. portals.py — كيف تُقرأ صفحة الدخول.
  5. fingerprint.py — قلب القرار: Judge.classify.
  6. engine.py — calibrate ثم Engine._run ثم _attempt.
  7. web/server.py — كيف يصل كل ذلك إلى الصفحة.
  8. web/ui.js — كيف تُعرض النتائج.

قبل أي تعديل وبعده

# الاختبارات الوحدوية (90 اختباراً، ~70 ثانية)
python3 -m unittest discover -s tests

# السيناريوهات الكاملة على راوترات وهمية
python3 KiraPass.py --selftest

# فحص البيئة
python3 KiraPass.py --check

# الرحلة كاملة عبر API بدون متصفح
python3 tools/checks/web_e2e.py

كل الاختبارات تعمل على 127.0.0.1 ضد mockportal.MockPortal، ولا تلمس أي شبكة حقيقية، ولا تخلط بياناتها ببروفايلاتك (عن طريق config.set_data_dir() إلى مجلد مؤقت).

اصطلاحات الكود

  • بايثون: from __future__ import annotations في كل وحدة، تلميحات أنواع على التوقيعات، docstring إنجليزي قصير يشرح السبب لا الماذا الظاهر، وتعليقات طويلة تشرح الدرس المستفاد من العطل القديم.
  • الأسطر: ~79–100 عمود، ولا يوجد linter مفروض في المستودع.
  • الاستثناءات: except Exception: مع # noqa: BLE001 مقصود دائماً — الأداة يجب ألا تموت أبداً بسبب رد غريب.
  • المفاتيح الآلية: كل سبب/حالة/كود هو نص إنجليزي صغير بحروف لاتينية وشرطات سفلية، ويُترجم في ui.js فقط.
  • التنقيح (redaction): أي شيء يُكتب على القرص أو يُرسل للواجهة يمرّ عبر دالة تنقيح (safe_url, _safe_url_shape, redact_fields, redact_review_body, safe_profile_snapshot, _scrub).
  • جافاسكربت: vanilla، "use strict"، لا build step، لا CDN، كل النص عبر t(key).

التفاصيل الكاملة مع أمثلة في دليل التعديل وأسلوب الكتابة.
