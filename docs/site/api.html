واجهات API

كل مسار HTTP في الأداة: وظيفته، من يستدعيه من الواجهة، وأين يُعالَج في web/server.py.

هذه الصفحة مولّدة آلياً من مصدر الكود مباشرة (tools/docs/build_docs.py). إن غيّرت الكود فأعد توليدها: python3 tools/docs/build_docs.py. الشرح اليدوي الأوسع في المعمارية ودليل التعديل وأماكن الخطر.
التفويض: كل مسار يتطلب رمزاً (?token= أو ترويسة X-KiraPass-Token) باستثناء المسارات الثابتة الأربعة الأولى التي تُخدم قبل التفويض عمداً حتى تستطيع الصفحة أن تطلب الرمز. العميل المحلي (127.0.0.1/::1) مسموح دائماً. المقارنة بـhmac.compare_digest.

أشكال الأخطاء

كل فشل يرجع {"ok": false, "error": "<مفتاح آلية>"} بحالة HTTP مناسبة (400 لمدخلات خاطئة، 401 بلا رمز، 404 لمفقود، 409 لتشغيل جارٍ). المفاتيح الشائعة: already_running · profile_invalid · bad_scope · profile_not_found · bad_json · server_gone (من جهة الواجهة عندما ينقطع السيرفر).
